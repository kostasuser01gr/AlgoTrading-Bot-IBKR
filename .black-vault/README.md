# Black Vault Registers

This directory stores the repository's hardening ledgers and generated compliance artifacts.

Tracked seed files:
- `Inventory.tsv`
- `LineCounts.tsv`
- `ScanLedger.json`
- `FindingsRegister.json`
- `ArtifactsLedger.json`
- `ProofLedger.tsv`
- `InvariantCatalog.json`
- `DecisionLog.json`
- `RiskRegister.json`
- `StateSnapshot.json`
- `MetricsLedger.json`
- `ComplianceLedger.json`
- `CostLedger.json`

Automation scripts under `scripts/github-cli/` and `scripts/ci/` update these files.
